## Retrieval failures and recovery

- Initial sandbox request to GitHub metadata failed DNS resolution. A network-enabled request succeeded.
- The browser retriever could read a rolling Ardour header but reported cache misses for exact-commit raw URLs. The source inspection used successful direct public HTTP reads and recorded hashes; browser errors were not promoted to source evidence.
- REAPER PDF fetch attempts were unavailable. The index establishes only the advertised manual version. Detailed editing/API findings use R01-R03.
- Nuendo's ADR modes/status subpages returned errors in this pass. N05 is sufficient for the limited ADR overview; no detailed state enumeration is attributed to the failed pages.
- A separate GNU licence-page request timed out. A06 and actual source notices supply the bounded licensing evidence used here.
